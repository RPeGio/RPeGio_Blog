# RPeGio_Blog

[简体中文](./README-zh-CN.md)

RPeGio 的个人博客站点，基于 [Astro](https://astro.build/) 与 [Astro Theme Pure](https://github.com/cworld1/astro-theme-pure) 主题构建。

[![GitHub deployments](https://img.shields.io/github/deployments/RPeGio/RPeGio_Blog/production?style=flat&logo=vercel&label=vercel)](https://rpegio-blog.vercel.app/)
[![GitHub License](https://img.shields.io/github/license/RPeGio/RPeGio_Blog?style=flat)](https://github.com/RPeGio/RPeGio_Blog/blob/main/LICENSE)

## 简介

这是我的个人博客，记录技术学习笔记、项目心得和日常思考。

## 本地开发

环境要求：

- [Node.js](https://nodejs.org/): 18.0.0+
- [Bun](https://bun.sh/) (推荐包管理器)

```shell
git clone https://github.com/RPeGio/RPeGio_Blog.git
cd RPeGio_Blog
bun install
bun dev
```
